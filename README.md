### 🏢 Employer–Worker Registration System

> A full-featured Java desktop accounting application for managing employer–worker relationships, wage records, and payment tracking — backed by PostgreSQL.

| 🔹 Feature | 📌 Details |
|---|---|
| 🔐 Admin Auth | Secure login to protect all records |
| 🏭 Employer Management | Register & manage employer profiles |
| 👷 Worker Management | Register workers with contact info |
| 📋 Work Records | Log daily work entries with wages |
| 💰 Payment Tracking | Track all payments in both directions |
| 🔍 Search | Instant lookup of workers & employers |

**Tech used:** `Java` · `Java Swing` · `PostgreSQL` · `JDBC`
